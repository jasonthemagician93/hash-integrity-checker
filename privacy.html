Privacy Policy

Last updated: June 2025  ·  v2.3.0
Short version: Hash Integrity Checker processes everything locally in your browser. Your files are never uploaded anywhere. Hashes are only sent to VirusTotal or MalwareBazaar when you explicitly click those buttons. No analytics, no tracking, no servers of our own.
01

What data this extension handles

Hash Integrity Checker operates entirely within your browser. The table below describes every category of data the extension touches, where it is stored, and whether it ever leaves your device.

Your files never leave your device. Hashing is performed entirely using the browser's built-in Web Crypto API and a local JavaScript implementation. No file content, filename, or metadata is transmitted to any server under any circumstances.

03

Chrome permissions explained

The extension requests the following Chrome permissions. Each is required for a specific stated purpose — none are used for data collection.

  • storage Saves expected hashes, verification history, settings, and your VT API key locally in your browser. Nothing is synced externally.
  • downloads Monitors when a download completes so it can prompt you to verify the file against your expected hash. The extension does not read, copy, or upload downloaded files.
  • notifications Shows a system notification when a monitored download finishes (can be disabled in Settings).
  • contextMenus Adds a right-click menu so you can set an expected hash or open a VirusTotal lookup without opening the popup.
  • activeTab Allows the content script to scan the currently active page for hash strings and highlight them.
  • scripting Used solely to write selected text to the clipboard when you choose "Copy to clipboard" from the right-click menu. No other scripting is injected.
  • tabs Reads the URL of the current tab to record where an expected hash came from. Used for the download source association check. URLs are stored locally only.
  • clipboardWrite Allows the extension to copy hash values to your clipboard when you click a Copy button.
04

Local storage and data retention

All data stored by the extension lives in chrome.storage.local on your device — it is never synced to Google's servers or any cloud service. It is visible only to this extension.

Verification history is capped at 100 entries by default (configurable in Options). Oldest entries are automatically removed when the limit is reached. You can clear all history at any time from the History tab or Options page.

Removing the extension from Chrome permanently deletes all stored data.

05

Analytics, tracking, and advertising

None. Hash Integrity Checker contains no analytics, no telemetry, no crash reporting, no usage tracking, and no advertising. No data about how you use the extension is collected or transmitted anywhere.

The extension does not use Google Analytics, Mixpanel, Sentry, or any similar service. There are no third-party scripts loaded at runtime beyond the VirusTotal and MalwareBazaar API calls you initiate yourself.

06

Children's privacy

Hash Integrity Checker is a security tool intended for use by adults, specifically security professionals and technically informed users. It is not directed at children under 13. We do not knowingly collect any information from children.
